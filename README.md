# Aeolus
Weather API in Python

[Set-up](https://github.com/DeadManLogan/Aeolus/wiki/Set%E2%80%90up)

### Config
Don't forget to add a config file similar to below:
```
class Settings:
    API_KEY = "api_key"
    REDIS_URL="redis://localhost:<port_of_redis>"
```
The config file should ALWAYS **be ignored**.
